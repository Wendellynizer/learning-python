## PYTHON HISTORY 

- <b>Guido van Rossum</b> - created Python starting in 1989 at CWI Netherlands.
- <b>Python 0.9.0</b> - first public release of Python with features such as functions,exceptions, and data types.
- <b>Python 2.0</b> - launched in <b>2000</b> with list comprehensions, garbage collections, and UNICODE support.
- <b>Python 3.0</b> - released in <b>2008</b> with major improvements.
- <b>2020s</b> - Python became popular, dominant in AI, Data Science, and Web Development.
